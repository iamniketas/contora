# План выравнивания Contora для macOS с Windows-версией

Дата аудита: 2026-08-23. Базовая версия macOS: `v0.6.9`.

## Принципы интерфейса

1. Главный экран показывает пользовательский контент и текущую задачу, а не устройство backend.
2. Запись, импорт и расшифровка имеют по одной точке управления и однозначное состояние.
3. История — постоянная часть навигации, а не вспомогательный список внутри панели записи.
4. Расшифровка выглядит как документ: время, спикер, текст. Управление появляется только там, где оно нужно.
5. Настройки содержат capture source, storage, MLX, endpoints, diagnostics, permissions, updates и integrations.

## Результаты аудита

| Область | Windows | macOS до аудита | Решение |
| --- | --- | --- | --- |
| История | Отдельная вкладка, поиск, фильтры, статусы | Маленький список внутри Recording | Постоянный sidebar с полной историей |
| Расшифровка | Компактные строки timestamp / speaker / text | Крупные карточки с повторяющимися controls | Плоский редактируемый документ |
| Спикеры | Глобальное имя и прослушивание примера | Имя повторяется в каждом сегменте | Единая панель спикеров над текстом |
| Outline | Create/update через API, ссылка на документ | Только локальный Markdown и clipboard | Нативный publish/update, Keychain, выбор collection |
| Технические данные | Частично вынесены в Settings | Backend, endpoint, model, paths на главном экране | Settings + скрытый session inspector |
| Управление | Основные actions сгруппированы по сценарию | Дублирование record/transcribe/backend actions | Один capture-блок и контекстные actions сессии |

## Этапы

### Этап 1 — информационная архитектура и базовый parity

- [x] Новый `NavigationSplitView`: capture + history слева, документ справа.
- [x] Полноценная история с поиском, фильтрацией и сортировкой.
- [x] Единый блок Record / Stop / Import и компактный progress активной задачи.
- [x] Компактные редактируемые строки расшифровки.
- [x] Глобальное переименование спикера и проигрывание его примера.
- [x] Технические метаданные сессии в inspector.
- [x] Outline API: credentials, collections, create, update, open document.
- [x] API token в macOS Keychain.

### Этап 2 — управление сессиями

- [x] Переименование, удаление и восстановление сессии из Recently Deleted.
- [x] Безопасное удаление импортированных сессий без перемещения внешнего source media.
- [x] Pin/favorites и быстрые smart filters: Today, This Week, Pinned, Unpublished.
- [ ] Массовый выбор и экспорт.
- [x] Полнотекстовый поиск по всем сегментам расшифровки.
- [ ] Подсветка совпадений поиска внутри расшифровки.
- [ ] Сохранение Outline document metadata в session manifest для переносимости архива.

### Этап 3 — профессиональная работа с расшифровкой

- [ ] Merge/split сегментов и смена спикера у выбранных сегментов.
- [ ] Undo/redo для текста и разметки спикеров.
- [ ] Непрерывный player с scrubber, скоростью и переходом к активному сегменту.
- [ ] Горячие клавиши для play/pause, save, следующего сегмента и назначения спикера.
- [ ] Поиск/замена по текущей расшифровке.
- [ ] Автосохранение с понятным индикатором состояния.

### Этап 4 — функциональный parity с Windows

- [ ] Analysis: summary, action items, decisions и копирование результата.
- [ ] Expected speakers/participants и назначение им diarization labels.
- [ ] Auto-publish в Outline после успешной обработки.
- [ ] Пользовательские названия сессий до начала записи.
- [ ] Экспорт TXT, Markdown, JSON, SRT и VTT из одного меню.
- [ ] Проверка VoiceOver, keyboard navigation, Dynamic Type и contrast.

## Критерии готовности

- Пользователь начинает запись или импорт максимум за один явный action.
- На главном экране нет endpoint, model ID, file paths и runtime diagnostics.
- В типичном окне одновременно видны минимум 8–12 коротких сегментов.
- Переименование спикера меняет все его сегменты и сохраняется в manifest.
- Повторный publish обновляет созданный Outline document, а не создаёт копию.
- История остаётся доступна при чтении и редактировании любой сессии.
- Все основные сценарии выполняются только с клавиатуры и корректно озвучиваются VoiceOver.
